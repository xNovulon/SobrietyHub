# Sobriety Hub

One link, every game. Detects the game you're in and loads its hub; an unsupported game says `wrong game gng`.

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/xNovulon/SobrietyHub/main/hub.lua"))()
```

| Game | Script |
|---|---|
| FERAL Animal Survival | `feral.lua` |
| Throw Food For Animals | `throw_food.lua` |
| Mog to Steal an Egg | `mog_helper.lua` |
